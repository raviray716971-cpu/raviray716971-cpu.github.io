Privacy policy

Last updated 22 November 2026. This policy covers Countdown Agent, a private tool used only by its owner.

Who uses it

Only the owner of the YouTube channels Sir Reginald Reviews and Professor Ullu Ki Class. No other people sign in to it.

What Google data it uses

  • YouTube upload access (youtube.upload): to publish videos to the owner's own two channels.
  • YouTube read-only access (youtube.readonly): to read view and like counts of the owner's own videos and public trending lists, so it can choose better topics.

How it is stored

The sign-in token is stored as an encrypted secret in the owner's private GitHub repository and used only by the owner's own automation. It is not shared with, sold to, or used by anyone else, and it is not used for advertising.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
